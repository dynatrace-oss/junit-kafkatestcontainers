# java.util
# ---------------------------------------------------------------------------

java.util.Collection#parallelStream() @ Globally discouraged functionality. 'parallelStream' internally starts additional thread pools/threads in an uncontrollable way.

@defaultMessage Avoid unchecked warnings by using 'Collections#empty(List|Map|Set)' methods. You might need to use the following notation to make type-inference work: 'Collections.<YourClass>emptyList()'
java.util.Collections#EMPTY_LIST
java.util.Collections#EMPTY_MAP
java.util.Collections#EMPTY_SET

# Locale related interfaces which we want to avoid to not have code which depends on the locale of the current machine
@defaultMessage Do not use methods that depend on the current locale. Either use Locale.ROOT or let the user define the locale.
java.util.Locale#getDefault()
java.util.Locale#setDefault(java.util.Locale)
java.util.TimeZone#getDefault()
java.util.Date#toString()

java.util.Objects#hash(java.lang.Object[]) @ Creates an array for every invocation and, thus, causes unnecessary Object churn (see e.g. APM-127974).
